# 视频、附件与存储运行边界

沿用现有上传接口、StorageService、FileRecord、视频播放器和 Range 响应。部署只执行增量 Prisma Migration，不重建账号或重播 Demo Seed。

上传前在 PostgreSQL 短事务中预留容量；所有实例共用现有文件引用锁。FileRecord 写入与预留结算同一事务提交。个人用量包含原件、播放版本、封面、附件、隔离文件，以及进行中的存储和临时空间预留。预留采用上限，实际文件落库后按真实大小计费，未用额度释放。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `STORAGE_USER_QUOTA_BYTES` | 10737418240（10 GiB） | 每个账号的文件及预留总量 |
| `STORAGE_CAPACITY_BYTES` | 0 | 本地为自动探测文件系统容量；S3/MinIO 必须填实际分配容量后才能上传 |
| `STORAGE_MIN_FREE_BYTES` | 2147483648（2 GiB） | 本地存储和临时盘必须保留的余量 |
| `STORAGE_PARALLEL_UPLOADS_PER_USER` | 2 | 每个账号正在接收的上传数 |
| `STORAGE_PARALLEL_UPLOADS_TOTAL` | 16 | 本实例组上传预留总数 |
| `VIDEO_QUEUED_PER_USER` | 3 | 每个账号的视频上传、排队与处理总数 |
| `VIDEO_QUEUED_TOTAL` | 50 | 全站视频在途任务上限 |
| `MEDIA_TEMP_PATH` | 存储目录下 `.media-tmp` | 可持久检查的临时工作区；可指定独立磁盘 |
| `MEDIA_CLAMSCAN_PATH` | 空 | 本地 clamscan 可执行文件路径；空值明确表示未扫描 |

保留 `VIDEO_UPLOAD_MAX_MB`（默认1024）、`RESOURCE_ATTACHMENT_MAX_MB`（默认100）、`VIDEO_PROCESSING_MAX_ATTEMPTS`（默认3，最多5）和 `VIDEO_ORPHAN_RETENTION_HOURS`（默认168，最少24）。对象存储只使用服务端代理下载，避免直接签名地址绕过后续权限变更。对象存储容量必须与实际桶配额保持一致。

上传和处理租约均为90秒，每30秒续租；视频队列每5秒检查失联任务。上传最长30分钟，排队24小时超时后释放，可按失败任务重新申请。认领标识同时约束视频状态和文件结算，失联处理者不能覆盖新结果。正常关闭停止认领并取消子进程。

ffprobe 最长30秒；转码最长30分钟；封面最长60秒。子进程合计输出最多1 MiB，转码最多2线程，格式探测限制为4小时、4K、60fps及8条轨道，输出大小受预留预算限制，并复核输出时长。Compose 给 API 设置2 CPU、2 GiB内存、128 PID和30秒关闭期限，不启动额外转码集群。

附件不会被应用执行或解压。配置 clamscan 后单进程串行扫描，等待队列最多64项；每项额外预留2 GiB扫描临时空间，扫描临时目录绑定该任务目录。120秒超时，输出最多64 KiB；风险、超限和执行故障隔离，不提供下载或投稿绑定。取消请求会停止扫描进程。未配置时返回 `unavailable`，历史文件为 `not_scanned`，均不能被描述为已扫描。病毒定义库须由部署环境维护；配置可执行文件不等于定义库可用。参数依据 [ClamAV 官方手册](https://github.com/Cisco-Talos/clamav/blob/main/docs/man/clamscan.1.in)。

所有应用媒体入口重新核对当前账号、校园资格、内容可见性与隔离状态。仅限制上传这一单项功能不会撤销阅读资格。公共资料图片仍遵循公开资料范围；私人草稿仅作者可读，后台读取已投稿材料须按原权限并记录审计。Nginx访问日志仅记录无查询参数的路径；前端播放凭据保存在当前页面内存中。

后台复用教程资源管理的处理页，显示容量、队列、租约、扫描状态、失败原因和安全清理结果。清理继续使用现有全业务字段及JSON历史引用检查，保护草稿、作品和课程版本。自动回收仅处理受控临时目录、失效预留和既有GC队列，不批量删除业务内容。
