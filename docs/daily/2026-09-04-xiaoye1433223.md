# 9 月 4 日 - 社区信息转换功能

今天的任务是「增加 1 个社区信息转换的功能」，后端前端都有改动：

## 一、后端（z）：社区内容导出/格式转换 API

给社区加了内容导出能力，帖子和评论可以导出成不同格式，一共三个接口：

- **导出单篇帖子**：支持 JSON 和 Markdown 两种格式。`format=json` 返回完整结构化数据（正文、内容块、作者、话题、关联内容、评论都包含）；`format=markdown` 返回 .md 文本，可以直接下载；
- **批量导出**：按条件批量导出帖子列表，返回 CSV 表格；
- **导出单篇评论**：可以单独导出某篇帖子下面的全部评论。

权限和校验这块也考虑到了：

- 必须登录，只能导出自己有权限查看的帖子；
- 批量导出每次上限 100 条，防止接口被人盗用；
- 帖子里的图片不搬文件，统一输出图片 URL。

核心转换逻辑：把内容块（contentBlock）一块块的 JSON 结构转成 Markdown 文本字符串；帖子里关联的课程标题会自动转成 `/courses/xxx` 的链接，导出之后点链接还能跳回课程页面。

这个功能是在 OpenCode Desktop 里做的，当时给了三个方向（内容格式导出、外部内容转社区帖子、帖子转其他内容类型），我们选的第三个——把社区帖子转成学习笔记、成就、作品集这类内容，导出 API 是其中第一步。目前接口已经实现并验证通过。
