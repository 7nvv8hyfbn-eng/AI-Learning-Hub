# 通识课程内容与插图

课程正文位于 `packages/demo-fixtures/src/curriculum/`，由 Mock、显式演示初始化和课程升级脚本共用。6 个主题共 24 门课程、72 个章节、144 个课时；每课时包含独立讲解、练习与要点。课时的 15 分钟包含阅读和练习，是学习安排估算。课程章节数、时长和 fixture 主题统计从实际内容推导；API 主题课程数按已发布且未删除的课程统计。

| 主题 | 课程数 | 课时数 |
| --- | ---: | ---: |
| 大模型 LLM | 6 | 36 |
| AI Agent | 5 | 30 |
| 图像生成 | 4 | 24 |
| 模型部署 | 4 | 24 |
| 智能硬件 | 3 | 18 |
| AI 安全 | 2 | 12 |

24 张课程封面和 48 张教学插画均为独立生成的 1200×900 WebP。小雪的角色与手绘画风保持一致；知识点、文件、替代文字、焦点及来源只在 `packages/catalog-assets/manifest.json` 维护。旧封面文件保留供历史版本使用。课程最后一节列出对应的官方文档或原始论文。

## 图片内容块

沿用 `LessonBlock` 与 `MediaAsset`，不增加数据库表。客户端选择稳定素材 ID 并填写说明；服务器绑定文件、校验公开性与用途，计算真实尺寸和比例：

```json
{
  "blockType": "image",
  "content": {
    "assetId": "素材ID",
    "fileId": "服务器绑定的文件ID",
    "alt": "小雪从书架寻找相关资料",
    "caption": "先检索资料，再结合资料回答。",
    "width": 1200,
    "height": 900,
    "aspectRatio": "4:3"
  }
}
```

发布时，正文图片和课程封面的文件 ID 固定在 `CourseVersion`。课程图片公开入口为 `/api/v1/public/media/:assetId/files/:fileId`，只有已发布快照声明的组合可访问。更换素材文件不会替换旧版本图片；修改图注保留已绑定文件，主动重选素材才绑定当前文件。新草稿不会继承旧快照的公开文件清单。

后台进入“课程管理”，选择课程，在课时中点击“添加图片”或已有图片的“编辑图片”。可选择现有课程插图，也可在素材库上传；填写 alt 和图注后保存草稿。内容块支持上移、下移和删除，预览确认后按现有流程发布。

## 初始化与显式升级

完整 Seed 仍受 `LOAD_DEMO_DATA=true` 限制。初始化只创建不存在的课程和主题；已有记录及版本不被重写。普通启动、部署、迁移和 bootstrap 均不运行课程升级。

在已构建服务端中先盘点，再根据报告显式执行：

```sh
npm run courses:upgrade-demo
npm run courses:upgrade-demo -- --apply
```

升级仅接受来源为 `demo_seed`、仍为原始发布第 1 版、完整旧模板和原始封面均未修改的课程。人工来源、导入内容、新草稿、新发布、正文修改及封面修订均跳过并报告原因。执行时与后台共用事务锁，再次核验资格。

升级创建第 2 版和新的章节、课时、图片块，保留课程 ID、旧版本、旧章节、学习进度、笔记和关联。只导入本次合格课程的素材；不会重播全量 Seed。已带 `xiaoxue-v2` 标记的课程再次执行为零写入。既有环境执行前须备份数据库、上传文件及配置，并在隔离副本验证升级、重复执行和旧行保留。

## 校验

学生端课程单测检查覆盖范围、时长统计、重复章节/课时/正文/图解/问题/要点以及每课图片数量。素材门禁校验 166 条唯一资产、实际尺寸、体积和二进制去重。服务端验证固定文件、草稿保护及升级跳过条件；飞牛隔离环境验证真实导入、版本发布、后台维护与响应式页面。
