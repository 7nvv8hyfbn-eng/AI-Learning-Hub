# 学习心得（2026年9月5日）

赵强

今天实训课加上晚上备赛，信息量很大，脑子有点转不过来，但有几个点是真听进去了，记一下。

## 一、四个概念终于不混了

之前 LLM、AI Agent、MCP、Skill 这几个词天天挂嘴边，让我正儿八经讲，其实讲不利索。今天老师带着一个一个抠，我算是理顺了：

- **LLM** 是大语言模型，本质是个"预测下一个词"的概率模型，它本身不会干活，只会生成文本；
- **Agent** 是在模型外面套了一层"能规划、能调工具、能看结果再决定下一步"的循环，模型从"嘴"变成了"脑子"；
- **MCP** 是模型连接外部工具和数据的统一接口协议，相当于给 Agent 装了标准插座，不用每接一个工具就重写一套对接；
- **Skill** 是封装好的能力包，把提示词、脚本、参考资料打包在一起，Agent 按需加载，而不是什么都塞进上下文。

我自己的理解：LLM 是发动机，Agent 是会开车的司机，MCP 是统一的交通规则，Skill 是车上装好的导航和空调。这么一类比，四个词的位置就清楚了。

还有个记错的地方被纠正了：我一直以为搞一套 AI 硬件实训设备几万块钱顶天了，老师说真正配齐能开课的 AI 实训环境是百万级投入。这也是为什么我们项目要做"受控实训"——学校机房不可能给每个学生开放真实服务器和显卡，用白名单命令加模拟日志把实训跑起来，是在真实约束下逼出来的方案，不是拍脑袋。

## 二、项目定位这一刀，砍得疼但是对

今天最关键的一件事，是老师把我们项目的定位掰正了：**题盒不是一个大而全的资料平台，是一个共创式互动学习社区。**

说实话，一开始我们什么都想往里放——课程、资讯、答题、作品展示，功能列表越列越长，觉得模块越多越厉害。今天被点醒：资料再多，学生还是"看视频能懂、上手就不会"；真正让知识留下来的，是学生学完之后自己写一篇教程帖、拿到积分、被同学点赞，优质帖再被收进课程资源。内容是从零基础学生的视角长出来的，不是老师从上往下灌的。这个"学生共创"才是题盒跟普通资源站的区别。

想明白这件事，之前拿不准的几个设计也顺了：为什么社区帖子要做一键导出笔记——因为学生学完最需要能带走的复习资料；为什么实训要做白名单——不是不想给权限，是机房真给不起。

## 三、备赛攻略给我浇了盆冷水

晚上我把世校赛的备赛攻略仔细过了一遍，越看越清醒，说三个最扎心的：

**第一，工艺流程占 60 分。** 我们做软件的，以前觉得"工序"是车床焊工的事，跟我们没关系。今天才明白，评委要看的是：你按什么顺序做、每道工序做到什么标准、关键难点你是怎么解的。我们把开发过程捋成需求调研、架构设计、双端开发、核心模块联调、容器化部署、实训运营迭代六道工序，再把乐观锁并发控制、有界召回、一键导出这三个有代码实证的难点拎成关键工序，心里才有了底。

**第二，数字必须真实，小数字也比空话强，但编一个死一个。** 我翻之前写的简介，什么"显著提升学习效率""深受学生欢迎"，全是正确的废话。攻略就一句话：没有实测数据就别写，去测。晚上我开始一项项对账：班级 38 人是名单数的，课程 24 门、实训 12 个、题库 80 道是种子数据里数的，工程文档 14 份是一份份点的。还没测的——首屏加载多少毫秒、100 条导出几秒、Docker 几分钟拉起——全部留空，周末掐表去。

**第三，知识产权今年查得特别严。** 没有软著受理通知书，一个字都不能写，"申请中"都不行。我们本来还想往成果里凑一条，老老实实删了。

## 四、最让我冒汗的一个发现

晚上对 GitHub 数据的时候发现一件事：我们公开仓库的提交记录里，绝大多数是老师演示用的账号，学生自己的提交没几笔。

这事的严重性在于——世赛明确要求保留完整开发痕迹，证明作品是学生做的。评委一点开仓库，提交记录全是老师账号，那我们这一个月干了什么？嘴上说功能是我们写的，记录呢？这跟我们担心被判定"AI 生成作品"是同一个雷：过程不可见，成果就不可信。

已经跟队友说好，接下来所有改动都走自己的账号正常提交、正常发 PR、正常 review 合并，把真实的开发过程补出来、留下来。宁可记录里有改 bug 的丑样子，也不要一份干干净净不像学生写的历史。

另外展示环节也一样：55 到 60 分钟的现场展示，评委想看的不是完美的成品秀，是失败记录和调试过程——你遇到过什么坑、怎么试错、怎么解决的。我们打算从提交记录里挑两三个真实 bug，把"问题→试错→解决"的故事线整理出来。敢把翻车记录放上去，反而说明东西真是自己做的。

## 五、明天开始做的事

1. 把六个实测数据跑出来：并发编辑拦截、首屏加载毫秒、CSV 导出秒数、Docker 拉起时间、后台真实使用数据、学生账号提交数；
2. 全队用自己的 GitHub 账号提交，把开发痕迹补齐；
3. 开始按三层结构排 55 分钟展示脚本，不再用之前 5 分钟的老本子。

今天最大的感受：做项目和交项目是两回事。功能跑通只是及格线，能把"为什么这么做、怎么做的、做到什么程度"讲清楚、拿得出证据，才是比赛要的东西。别再想着包装了，东西硬，比什么都强。
