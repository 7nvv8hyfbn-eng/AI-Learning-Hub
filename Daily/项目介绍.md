## 一、项目名称

**智训 Agent—— 高职 AI 实训平台开发与实践应用**

## 二、项目设计

本项目面向职业教育行业，针对高职 AI 实训资源碎片化、实训环境搭建门槛高的问题，由 4 名学生分工完成。筹备阶段完成需求调研、多套技术方案比选；实施阶段完成 Agent‑MCP‑Skill 整体架构开发、功能迭代与系统调优；展示阶段采用平台实操演示、过程留痕材料联动形式。

## 三、工艺流程

全流程共 6 道工序：需求调研分析→架构方案设计→Agent 与 MCP 服务开发→Skill 技能库封装→系统联调测试→项目迭代验证。其中**Skill 技能库封装**是关键工序，难点在于多步骤工作流程标准化封装难度大，我们采用子 Agent 角色固化方案，将任务执行耗时由 42 分钟压缩至 15 分钟。第 3 步引入 MCP 外部服务调用机制，替代传统本地静态数据处理方式。

## 四、核心技能

团队成员掌握 Web 前端开发、Agent 脚本开发、版本控制 GitHub 管理；具备项目统筹管理、现场调试排障能力，体现在多轮版本迭代、故障复现与问题修复场景。并且完成项目全流程文档、会议纪要、迭代记录全套归档备审。

## 五、项目创新

创新点一（技术）：构建 Agent‑MCP‑Skill 协同实训架构，与传统 AI 实训平台相比，任务自动化执行效率提升 64%。
创新点二（形式）：采用子 Agent 固化角色提示词方案，降低 AI 角色配置的重复工作量。
创新点三（工具应用）：建立可复用 Skill 技能库，实现多步骤业务流程一键调用。

## 六、主要成果

完成 AI 实训平台系统 1 套、可复用 Skill 技能库 1 套；输出完整 GitHub 开发留痕仓库；团队完成多版本原型迭代，前期原型题盒 Daily 迭代升级为本项目，产出全套项目申报、路演答辩材料。

## 七、应用价值

已应用于校内 AI 实训教学，实训任务配置耗时大幅缩减；为职业教育 AI 实训提供轻量化解决方案；整套架构方案可转化为实训教学案例，可供同类院校参考复用，助力职业院校 AI 实践教学落地。

## 八、未来展望

团队将在半年内扩充 Skill 技能库数量；一年内完善平台测试用例，优化 MCP 服务兼容性；三年达到形成标准化实训教学模块，向更多职业院校推广落地。
