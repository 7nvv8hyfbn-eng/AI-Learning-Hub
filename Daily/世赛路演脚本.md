# 世界技能大赛 · 世赛路演脚本

> 项目：AI 数智化学习平台
> 角色：项目经理（主讲人）· 前端（演示操作）· 后端（技术兜底）
> 目标：2 分钟内让评委听懂 + 记住 + 想看

---

## 一、一句话主张（全程反复强调）

> **"高校学生学 AI 普遍'听懂不会做'，我们让学生在受控环境里亲手做出来，再用统一测评验证学会没有。"**

（开场、结尾、回答提问时，都回到这句话。）

---

## 二、开场 30 秒（项目经理主讲，抓注意力）

> 各位评委，我们做的不是又一个网课平台。
>
> 今天高校里 AI 教学最大的痛点是——学生看了一堆视频、记了一堆概念，**一动手就懵**：模型怎么部署？Agent 怎么搭？调出来的结果对不对？
>
> 我们的平台，把「学习 → 实践 → 验证」做成一个完整闭环：学生学完概念，**在受控的模拟实验室里亲手把模型跑起来**，再用统一测评确认真的学会。
>
> 接下来我用一个真实学生的视角，90 秒带大家走完这个过程。

---

## 三、现场演示主流程（约 90 秒，前端操作）

### 第一幕：登录与个性化（10 秒）
- 用学生账号 `student@example.com` 登录（**提前登录好，现场不输密码**）
- 一句话：*"这是一位正在学 AI 的大二学生，他选择了自己感兴趣的方向。"*

### 第二幕：学习路径（15 秒）
- 进入「学习主题」→ 选「大模型 LLM」
- 展示学习路径：AI 通识 → Python 基础 → 大模型原理 → Prompt/RAG → 模型部署
- 一句话：*"从认知到实践，是一条完整的路径，不是零散课程。"*

### 第三幕：受控实训 ⭐ 核心亮点（40 秒）
- 进入「实训中心」→ 打开「部署你的第一个 AI 模型」实训
- 现场操作：启动服务 → 检查健康状态 → 验证接口
- 展示**命令行交互、实时日志、步骤反馈**
- 一句话：*"学生在真实感的命令行里操作，系统每一步都有受控校验和即时反馈——不是看视频，是真动手。"*

### 第四幕：统一测评验证闭环（15 秒）
- 进入「挑战与测评」→ 完成一次测评
- 展示成绩、知识正确率、成长数据
- 一句话：*"做完实训，用测评验证是否真的学会，结果沉淀到成长体系。"*

### 第五幕：管理后台运营（10 秒，可选）
- 切到管理后台，展示课程/实训/用户的可视化管理
- 一句话：*"内容是运营人员持续维护的，不是一个静态 Demo。"*

## 五、评委提问应答（提前背熟）

| 可能的问题 | 应答要点 |
|-----------|---------|
| 和 MOOC/慕课有什么区别？ | 我们不是放视频，是**受控实训**：学生在命令行真操作、有校验、有反馈，学了能验证 |
| 受控实训是不是假的？ | 是**安全的设计**：用白名单命令 + 状态机 + 模拟日志，保证安全可交付，同时保留了真实操作的体验 |
| 技术难点在哪？ | 实训状态机、SSE 实时日志、Agent 流程可视化、题盒成绩回写，前后端契约化协作 |
| 学生数量多怎么办？ | 受控实训不占真实资源，不建独立容器，可水平扩展 |
| 数据怎么保证真实？ | 演示账号预置完整数据：学习记录、成长轨迹、资源中心图文视频 |
| 团队怎么分工的？ | 前端负责交互与视觉，后端负责接口与稳定，我负责需求拆解、进度管控、验收闭环，Git PR 全流程留痕 |
